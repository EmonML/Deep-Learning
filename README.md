# Brain Tumor Classification using CNN
A Deep Learning-based Brain Tumor Classification system that uses **Convolutional Neural Networks (CNNs)** to classify brain MRI images into four categories:

* **Glioma**
* **Meningioma**
* **No Tumor**
* **Pituitary Tumor**

---

## Project Overview

Brain tumors are abnormal growths of cells within the brain. Early identification and classification of brain tumors can assist medical research and clinical workflows.

In this project, a **CNN-based image classification model** is developed to automatically classify brain MRI images into four different categories.

The complete workflow includes:

**Dataset → Data Preprocessing → Data Augmentation → CNN → Training → Evaluation → Visualization → Prediction**

> **Disclaimer:** This project is developed for educational and research purposes only. It is not intended to replace professional medical diagnosis.

---

## Objectives

The main objectives of this project are:

* Classify brain MRI images into four categories.
* Build a CNN-based image classification model.
* Perform image preprocessing and augmentation.
* Visualize dataset distribution.
* Monitor training and validation performance.
* Evaluate the model using multiple metrics.
* Generate a confusion matrix and classification report.
* Build a user-friendly prediction interface.

---

## Classes

| Class      | Description                                 |
| ---------- | ------------------------------------------- |
| Glioma     | Brain tumor originating from glial cells    |
| Meningioma | Tumor originating from the meninges         |
| No Tumor   | MRI image without a detected tumor category |
| Pituitary  | Tumor associated with the pituitary gland   |
